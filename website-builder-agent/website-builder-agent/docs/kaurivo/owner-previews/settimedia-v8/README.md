# Settimedia Oy – Kaurivon V8 sisäinen uudistusesitys

**Käyttötarkoitus:** näytä Danille, mitä oikeasti nelisivuinen, mobiiliystävällinen verkkosivudemo voi tarkoittaa. Tämä ei ole Settimedia Oy:n hyväksymä asiakasjulkaisu.

## Lähde
- Nykyinen sivusto: https://settimediafin.com/
- Yhtiön tarjoamat palvelut: sisältöstrategia, postaukset, valokuvat ja grafiikat, raportointi
- Yhteystiedot: info@settimediafin.com, 040 524 5559
- Tiimi ja yhteystiedot: https://settimediafin.com/about/
- Mahdolliset alkuperäiset valokuvat linkittyvät niiden alkuperäiseltä palvelimelta, joten käyttöoikeus ja luotettava saatavuus pitää tarkistaa ennen asiakasesitystä / julkaisua.
- Alkuperäinen bränditunnus ja viralliset värit eivät ole saatavilla todennettuna aineistona. Tämän konseptin neutraali värimaailma ja Settimedia-tekstityyli eivät väitä korvaavansa hyväksyttyä brändiä.
- Alkuperäisen palvelut-alasivun sisältöä ei ole saatu kokonaisuutena luettua. Tämä versio käyttää vain varmennettavissa olevia palvelukategorioita ja välttää keksityt hinnat, saavutukset ja asiakascaset.

## Tavoitellut sivut
Koti (index.html), Palvelut (palvelut.html), Meistä (meista.html), Yhteys (yhteys.html).

## Tekniset periaatteet
- Ei tekoälyllä piirrettyjä liikkuvia tuote-/ihmiskuvituksia.
- Todelliset alkuperäiset valokuvat ovat esillä vain viitteellisinä; tekijänoikeuksista sovittava.
- Ei feikkilomaketta. Yhteydenotot käyttävät alun perin julkista sähköpostia ja puhelinnumeroa.
- Noindex, nofollow, näkyvä sisäisen demo -merkintä.
- Staattinen HTML, CSS ja JS ovat GitHubissa versionhallittavissa, mutta asiakasmuokattava WordPress-versio ei ole vielä toteutettu.
- Ei väitetä riippumatonta 9,5/10 arvostelua tai asiakkaan hyväksyntää.
