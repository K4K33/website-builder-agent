Ennen yhteydenottoa

Voiko palvelut räätälöidä yrityksen tarpeisiin?

Kyllä. Settimedia kertoo alkuperäisellä sivustollaan, että palvelupaketteihin voidaan valita yritykselle sopivia osa-alueita.

Mitä palveluihin kuuluu?

Yritys esittelee sisältöstrategian, postaukset, valokuvat ja grafiikat sekä raportoinnin. Tarkempi kokonaisuus sovitaan yhteydenotossa.

Miten saan lisätietoja hinnasta?

Hintaa ei ilmoiteta tässä demossa, koska yritys ei ole vahvistanut julkista hinnastoa tätä konseptia varten. Ota yhteyttä ja pyydä tarpeisiin sopiva tarjous.
