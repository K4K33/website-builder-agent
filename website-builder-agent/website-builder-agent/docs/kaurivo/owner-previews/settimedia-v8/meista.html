Meistä · Settimedia

Tunnemme somen.
Haluamme tuntea teidät.

Jokaisen yrityksen ääni on erilainen. Settimedia tarjoaa mukautettavia sosiaalisen median palveluita osana pitkäjänteistä yhteistyötä.

Lähtökohtamme

Sisällön pitää tuntua yritykseltä itseltään.

Settimedia haluaa rakentaa jokaiselle yritykselle sopivan kokonaisuuden. Yhteistyöhön voi kuulua kanavien hallintaa, sisällöntuotantoa, asiakkaiden kanssa käytävää vuorovaikutusta ja analytiikan seurantaa.

Keskustelu lähtee yrityksen omista tarpeista, ei valmiista kaikille samanlaisesta paketista.
