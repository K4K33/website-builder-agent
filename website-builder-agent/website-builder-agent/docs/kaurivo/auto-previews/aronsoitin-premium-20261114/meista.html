Aron Soitin

Aron Soitin Oy on Helsingissä toimiva musiikkialan yritys. Sen verkkokaupassa ja myymälässä on uusia ja käytettyjä soittimia, tarvikkeita sekä äänentoistolaitteita. Lisäksi yritys tarjoaa soitinhuoltoa, treenitiloja, klubitilaa ja esitystekniikan vuokrausta.

Tässä suunnitteludemossa tuotetiedot ja kuvat perustuvat yrityksen omaan julkiseen verkkosivustoon. Kuulumisia ja viimeisimmät varastotuotteet voit tarkistaa suoraan verkkokaupasta.
