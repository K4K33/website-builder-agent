Vastaukset perustuvat Aron Soittimen julkaistuihin tietoihin.

Missä Aron Soittimen myymälä sijaitsee?

Sahaajankatu 14, sisäpiha, 00880 Helsinki. Pysäköinti on maksutonta sisäpihalla ja Sahaajankadun varressa.

Voinko tilata soittimia verkosta?

Kyllä. Käytössä on Aron Soittimen oma verkkokauppa, jossa tilaus, ostoskori ja maksaminen hoidetaan turvallisesti. Avaa verkkokauppa.

Tarjotaanko soitinhuoltoa?

Kyllä. Kielisoittimille, rummuille ja symbaaleille on huolto-, korjaus- ja entisöintipalveluja. Katso huoltopalvelut.
