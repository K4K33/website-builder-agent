Maalaus Valo Oy on perustettu vuonna 2019 veljeksistä Petteri ja Teemu Valo. Yritys tarjoaa maalauksen ja pintakäsittelypalveluita pääkaupunkiseudulla. Petteri on toiminut ammattimaalarina vuodesta 1991.
