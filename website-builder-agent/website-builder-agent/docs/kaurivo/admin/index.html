ADMIN ACCESS

Tervetuloa takaisin.

Kirjautuminen sallitaan vain vahvistetulle Kaurivon hallintatilille.

Ei Gmail-salasanasi. Tämä pitää luoda erikseen kirjautuneen Kaurivo-adminin Aseta salasana -kohdassa, ja salasana kuuluu valitulle sähköpostitilille.

TAI

Jos sähköpostipalvelun lähetysraja on täynnä, voit asettaa salasanan jo kirjautuneessa Safari-ikkunassa. Älä lähetä kirjautumisviestejä toistuvasti.

Sähköpostilinkki on varakirjautuminen. Jos käytät linkkiä, vahvista se tässä sovelluksessa, älä Safarissa.

VAHVISTA TÄSSÄ SOVELLUKSESSA

Avaa Gmail ja kopioi sähköpostin kirjautumislinkki painamalla linkkiä pitkään ja valitsemalla Kopioi linkki. Älä avaa linkkiä Safarissa.

Jos sähköpostissa näkyy 6–8 numeroinen vahvistuskoodi, syötä vain koodi. Jos viestissä näkyy linkki, kopioi sen koko osoite avaamatta linkkiä.

Supabase-kirjautumisen käyttöönotto

Lisää Supabase-projektin Authentication → URL Configuration → Redirect URLs -kohtaan tämä täsmällinen osoite:

https://k4k33.github.io/website-builder-agent/kaurivo/admin/

Kaurivon admin-tilien on oltava vahvistettuja. Kertakäyttökoodin saa sähköpostiin, kun Supabase → Authentication → Email Templates → Magic Link -viestipohjaan lisätään {{ .Token }}.
