Verhoilijamestari Anna

Kalusteen

Kudelman yrittäjä Anna on opiskellut huonekalujen restaurointia ja verhoilua. Hän valmistui verhoilijamestariksi syksyllä 2025.

Verhoomolla kunnostetaan huonekaluja sekä perinteisin että modernein menetelmin. Sopivat materiaalit valitaan kalusteen iän, rakenteen ja käyttötarpeen mukaan.
