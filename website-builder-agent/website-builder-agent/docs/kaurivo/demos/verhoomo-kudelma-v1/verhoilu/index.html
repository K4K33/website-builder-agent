Kudelma / Verhoilutyöt

Hyvällä
kalusteella
on aikaa.

Verhoilussa ratkaisu lähtee aina kalusteesta. Sen rakenne, ikä ja tuleva käyttö ohjaavat materiaalien ja työtapojen valintaa.

Perinteinen verhoilu

Vanhojen pystyjousitettujen huonekalujen kunnostaminen esimerkiksi meriheinän, haapalastun ja jouhien avulla. Kudelma kertoo käyttävänsä kalusteen ikään ja tyyliin sopivia perinteisiä menetelmiä.

Teollinen eli moderni verhoilu

Modernien huonekalujen siksak-jousien, tekstiilivöiden, vaahtomuovipehmusteiden ja päällisten korjaus tai vaihto kalusteen tarpeen mukaan.

Kankaat ja tarvikkeet

Kudelmalta voi hankkia verhoilukankaita, nahkaa, täytemateriaaleja, jousia ja työkaluja. Sopivuus ja saatavuus kannattaa tarkistaa suoraan verhoomolta.

Miten tarjous etenee?

Lähetä kalusteesta kuva ja toiveesi sähköpostilla. Saat hinta-arvion, jonka hyväksymisen jälkeen sovitaan aikataulusta ja materiaaleista. Lopullinen työ ja maksu sovitaan yrityksen kanssa. Tarkat vaiheet alkuperäiseltä sivulta ↗.
