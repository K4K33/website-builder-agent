Käsityöperinne

Sama verstas, monta sukupolvea.

Verhoomo Kuusivaara toimii Artekin huonekalutuotannon yhteydessä Littoisissa. Työssä yhdistyvät uusien kalusteiden verhoilu ja vanhojen huonekalujen uudelleenverhoilu.

Artekin satulavyöverhoilu on yksi yrityksen pitkäaikaisista erikoisosaamisalueista.

Verhoilijan työ on myös pehmusteiden, rakenteiden ja materiaalien tuntemusta. Juuri siellä näkyy vuosien harjoitus.
