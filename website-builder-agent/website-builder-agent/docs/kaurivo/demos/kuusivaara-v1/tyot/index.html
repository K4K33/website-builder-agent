Näkyvät verhoilukuvat ovat Pexelsin lisensoituja esimerkkikuvia, eivät Kuusivaaran töitä. Alkuperäiset historiakuvat voi katsoa yrityksen omalta sivustolta. Asiakassivun lopulliset kuvat edellyttävät hyväksyntää.

Suuria ja pieniä kohteita

Satulavyöklassikoista Savoyn kalusteisiin.

Verhoomo kertoo tehneensä myös Helsingin Savoy-ravintolan tuolien ja sohvien uudelleenverhoilua. Artekin tuotantoyhteistyö sekä yksityisasiakkaiden uudelleenverhoilut muodostavat yrityksen työn perustan.
