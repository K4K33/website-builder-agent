Verhoomo Kuusivaara · Littoinen

Verhoilun jälki näkyy.

Kuvallinen katsaus Kuusivaaran verhoiluun ja historiaan. Yksittäisten kuvien tarkkoja asiakaskohteita ei ole tunnistettu, joten emme liitä niihin keksittyjä työnimiä.

Perheyritys vuodesta 1913VERHOOMO KUUSIVAARA

Kuvat viittaavat yrityksen alkuperäiseen verkkosivuun. Niiden latautuminen, käyttöoikeus ja tarkka kohdeyhteys vaativat vahvistuksen ennen asiakaskäyttöä.

Suuria ja pieniä kohteita

Satulavyöklassikoista Savoyn kalusteisiin.

Verhoomo kertoo tehneensä myös Helsingin Savoy-ravintolan tuolien ja sohvien uudelleenverhoilua. Artekin tuotantoyhteistyö sekä yksityisasiakkaiden uudelleenverhoilut muodostavat yrityksen työn perustan.
