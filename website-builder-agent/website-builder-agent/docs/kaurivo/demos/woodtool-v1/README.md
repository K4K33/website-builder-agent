# WOODTOOL — bilingual premium design exercise

This is an **independent Kaurivo design concept**, not the company's
official website, domain or client-approved production deliverable.

- Official original: https://woodtool.fi/ (FI); https://woodtool.fi/sv/ (SV)
- Studio: PM Woodtool Ab Oy, Nagu / Nauvo
- Contact: info@woodtool.fi; Petri 0400 814 160; Marika 040 751 9313
- Ten pages, five fully translated routes per language:
  FI: /, /palvelut/, /tyot/, /verstas/, /yhteys/
  SV: /sv/, /sv/tjanster/, /sv/referenser/, /sv/verkstaden/, /sv/kontakt/
- Product/services carried over: solid-wood stairs, doors, windows,
  furniture and panel planing; design, crafting, finishing,
  optional tear-down and installation.
- Actual source project photographs (not invented) with closeup dialog,
  four functional gallery filters, and the 42 named source portfolio
  works retained in archive lists. Some original photographs have not
  been reproduced in the curated demo and link to the official gallery.
- Semantic navigation, FI/SV same-route switching, mobile menu with Escape,
  large live preview, and an optional pointer-aware light/material layer.
  All main content readable without JS and with reduced motion.

## Non-negotiable blockers before customer delivery
- Logo and photographs are sourced from the original public website as
  reference evidence only. **Their presence does not grant a license.**
  Media reuse, self-hosting, owner signoff, and rights must be resolved.
- No fake lead collection. The original page used phone/email links, and
  the concept transparently uses direct calls/email rather than pretending
  to deliver a quotation form.
- WordPress or comparable client CMS edit/save/publish and recovery have
  not been implemented/tested.
- Any claimed 9.5/10 independent score is PENDING, regardless of the
  static/browser QA results.
- This is a public noindex design exercise when deployed, NOT ready to
  transfer to the client or market as an official WOODTOOL site.

Source/browser proof: GitHub Actions workflow woodtool-demo-qa.yml,
incl. original/redesign desktop and mobile screenshots and navigation,
gallery, image delivery, pointer-motion and reduced-motion tests.

Visual brief: this client is a carpentry workshop and original portfolio
is full of real work; visual strategy uses dark architectural workshop
layout, genuine solid-wood images, compressed high-contrast sans-serif
typography and restrained oak/gold accents, rather than the sepia painter
template or fabricated glossy designer-furniture imagery.
