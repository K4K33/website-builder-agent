Puusepäntyötä Nauvosta.

Woodtool on pieni perheyritys, joka valmistaa puutuotteet asiakkaan tarpeisiin. Verstas palvelee myös Turun seudun asiakkaita.

Työvälineet ja materiaali

Kun työn jäljen huomaa.

Puuvalinta, profiilien muodot ja pintakäsittely suunnitellaan jokaisen työn tarpeisiin. Toteutamme pienempiä kalusteita ja suurempia puusepänkokonaisuuksia.

Yhdessä asiakkaan kanssa

Työ alkaa tarpeesta.

Työn laajuudesta riippuen mukana ovat suunnittelu, valmistus, pintakäsittely ja tarvittaessa purku sekä asennus. Woodtoolin asiakkaisiin kuuluu sekä kotitalouksia että yrityksiä.

Vanhat rakennusosat ja perinteiset profiilit ovat yksi osa työkuvastoa: työnäytteissä näkyy niin ikkunoita kuin massiivipuisia oviakin.
