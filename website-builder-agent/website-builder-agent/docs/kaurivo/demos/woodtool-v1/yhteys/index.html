Ota yhteyttä omasta työstäsi.

Usein kysyttyä
Teettekö töitä myös yrityksille?

Kyllä. Woodtool palvelee sekä yrityksiä että kotitalouksia.

Voiko oven tehdä vanhan mallin mukaan?

Kyllä. Woodtool valmistaa ovia ja ikkunoita myös perinteisten mallien mukaan.

Sisältyvätkö suunnittelu ja pintakäsittely?

Woodtoolin palveluihin kuuluvat suunnittelu, valmistus ja pintakäsittely. Työn laajuus sovitaan kohteen mukaan.

Onko tuotteilla verkkokauppa?

Esitellyt työt ovat mittatilaustöitä. Ota yhteyttä suoraan Woodtooliin tilaus- tai tarjousasioissa.
