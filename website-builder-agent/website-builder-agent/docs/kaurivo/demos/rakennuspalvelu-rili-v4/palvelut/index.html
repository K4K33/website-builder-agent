Hyvä tietää

Remontin suunnittelu.

Yrityksen ohjeissa kylpyhuoneremontin kestoksi arvioidaan usein noin 1–3 viikkoa. Työn laajuus ja tarvittavat kuivausajat vaikuttavat aikatauluun.

Kuinka paljon kylpyhuoneremontti maksaa?

Koko, materiaalit ja mahdolliset rakennemuutokset vaikuttavat hintaan. Tarkempi arvio tehdään kohteen perusteella.

Tarvitaanko remonttiin lupia tai valvojaa?

Taloyhtiön muutostyöilmoitus, viranomaisluvat ja mahdollinen valvonta riippuvat työn sisällöstä. Selvitä vaatimukset ennen remonttia.

Saako remontista kotitalousvähennystä?

Vähennyksen ajantasaiset ehdot ja määrät kannattaa aina tarkistaa Verohallinnosta ↗.

Miten remonttiin valmistaudutaan?

Suojaa tai siirrä työtilassa olevat tavarat, sovi kulkureitit ja aikataulu sekä mahdolliset käyttökeskeytykset urakoitsijan kanssa.
