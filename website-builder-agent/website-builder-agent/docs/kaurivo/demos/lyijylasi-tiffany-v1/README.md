## What was built
Five distinct Finnish routes: home, services (four areas), all 23 source gallery images (three filterable groups), original five-stage order process, and source-verified contacts with FAQ. Brand uses the real name and cool-blue / warm-orange colors without inventing a new logo. Responsive navigation, gallery modal and mailto-draft form are built into the static demo. It never submits a message itself.

## Source fidelity & image rights
Source: original public pages read 2026-11-09. The recorded image IDs in `data/demo_provenance/lyijylasi-tiffany-v1.json` come from the source gallery and are served by the original Wix image CDN. Product descriptions and specific project stories were *not* invented. Image link availability, pixel-level subject/crop review and reuse permission remain unchecked. The original owner's contact form is linked, not impersonated.
