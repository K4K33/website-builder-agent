Ennen yhteydenottoa

Voinko tilata lasityön oman kuvan tai idean perusteella?

Kyllä. Yritys kertoo suunnittelevansa tilaustöitä asiakkaan toiveiden mukaan. Voit lähettää kuvia tilasta tai referenssejä haluamastasi tyylistä.

Korjaatteko vanhoja Jugend-ikkunoita?

Kyllä. Yrityksen palveluihin kuuluvat vanhojen lyijylasi- ja Tiffany-ikkunoiden sekä muiden taidelasien korjaus ja restaurointi.

Kuinka kauan lasityön valmistus kestää?

Yrityksen ilmoittama tyypillinen toimitusaika on 2–8 viikkoa. Aika riippuu työn laajuudesta ja vahvistetaan tarjouksen yhteydessä.

Miten saan hinta-arvion?

Ota yhteyttä ja kuvaile kohde. Yrityksen ilmoittaman käytännön mukaan saat kirjallisen tarjouksen, jossa kerrotaan työ, materiaalit, hinta ja aikataulu.
