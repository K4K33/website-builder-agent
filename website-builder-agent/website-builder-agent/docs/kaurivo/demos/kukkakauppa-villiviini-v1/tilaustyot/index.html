Kukkakauppa Villiviini / palvelut

Kukat kuuluvat
elämään.

Juhlaan, arkeen, iloon ja suruun. Villiviinin kukkasidonta tehdään tilaisuuden ja toiveiden mukaan.

Hääkukat ja juhlat

Morsiuskimput, sulhasvieheet, kaasojen kukat sekä juhlapaikan kukitukset ja somisteet. Villiviiniltä saa myös vuokrattavia somisteita. Tutustu alkuperäiseen palvelukuvaukseen ↗

Surukukat

Surukimput, surulaitteet ja muut muistotilaisuuden kukat. Kukat voidaan toimittaa toiveiden mukaan myös kappeliin tai muistotilaisuuteen Lahden alueella.

Viikkokimput

Viikkokimput toimitettuna kotiin kerran viikossa tai joka toinen viikko sopimuksen mukaan. Kysy floristilta budjettiin ja kukkatoiveisiin sopivasta toteutuksesta.

Yritysten kukat

Kukka-asetelmat tilaisuuksiin ja toimitiloihin sekä kukkakurssit yritysryhmille. Kysy tapauskohtaisesta toteutuksesta ja ajankohdasta.

Verkkokauppa

Villiviinin eKukka-kaupassa voi tutustua ajankohtaiseen valikoimaan ja tehdä kukkatilauksia. Avaa oikea verkkokauppa ↗

Tilaustyöt

Kerro
ideastasi.

Varmista saatavuus ja tarjous suoraan Villiviinin henkilökunnalta. Demo ei kerää yhteystietojasi.
