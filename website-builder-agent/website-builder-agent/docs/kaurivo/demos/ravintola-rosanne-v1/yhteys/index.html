ROSANNEN TAUSTA

Laukaassa vuodesta 1999

Cafe Anne-Maria Oy:n toiminta alkoi Jyväskylän kauppahallissa vuonna 1993. Ravintola Rosanne aloitti Laukaassa marraskuussa 1999. Ravintolan nykyisen yritysesittelyn mukaan asiakaspaikkoja on 125, lisäksi kesäterassi.

Yrityksen vanhalla sivulla mainitaan myös Nightclub Rosanne, mutta sen nykyistä toimintaa ei ole varmistettu. Tietoa ei markkinoida tässä demossa nykyisenä palveluna.
