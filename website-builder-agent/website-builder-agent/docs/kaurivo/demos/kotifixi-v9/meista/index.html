TIETOA KOTIFIXISTÄ

Mitä Kotifixi tekee?

Kotifixiltä voi kysyä apua pihanhoitoon, kodin askareisiin ja pieniin kunnostustöihin. Voit myös tiedustella, onnistuuko jokin muu yksittäinen työ.

YHTEYDENOTTO

Yhteydenotto ja työn sopiminen

Kotifixin omilla verkkosivuilla kerrotaan, että työn hintaa voi tiedustella puhelimitse tai sähköpostilla. Erillistä tarjouspyyntölomaketta ei aina tarvita.

Kerro, missä apua tarvitaan ja millaisesta työstä on kyse. Näin työn sisältöä ja kustannuksia voidaan arvioida ennen sopimista.
