ALPPILAN OMA TRIMMAAMO

Sama paikka.
Paljon koiratarinoita.

Helsingin Koiratrimmaamon tarina alkoi vuonna 1975 Linnanmäen kupeessa. Yli viisikymmentä vuotta myöhemmin arjessa näkyvät yhä rauhallinen käsittely, ammattitaito ja koiran yksilölliset tarpeet.
