Julkisilla

Raitiovaunu 3 ja bussi 23 tuovat Linnanmäen pohjoisen pysäkin lähelle. Pasilan asemalta on noin 1,4 km kävelymatka tai jatkoyhteys bussilla.

Autolla

Viipurinkadulla ja lähikaduilla on maksullista pysäköintiä. Vastapäätä on myös Linnanmäen maksullinen pysäköintialue. Tapahtuma-aikoina kannattaa varata saapumiseen enemmän aikaa.

Esteettömyys

Vanhan kiinteistön sisäänkäynnillä on kaksi porrasta. Soittamalla etukäteen voit sopia koiran noudosta ja palautuksesta kadulle; yrityksen mukaan korttimaksu onnistuu myös ulkona katutasossa.
