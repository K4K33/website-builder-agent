ENNEN KÄYNTIÄ

Hyvä tietää.

Voiko kynnet tulla leikkauttamaan ilman varausta?

Kyllä, kun trimmaamolla on vapaa hetki. Soita kuitenkin ennen tuloa, sillä paikallaoloaika vaihtelee.

Mikä on peruutusehto?

Peruuta aika viimeistään 24 tuntia ennen varauksen alkua. Tätä myöhemmin perutuista tai käyttämättä jätetyistä ajoista voidaan veloittaa 50 % hinnasta.

Milloin kannattaa varata kevään trimmaus?

Maalis–heinäkuu on yrityksen mukaan kiireisintä aikaa. Varaus kannattaa tehdä hyvissä ajoin, ja seuraavan käynnin voi suunnitella jo edellisen yhteydessä.

Entä jos en tiedä, sopiiko nyppiminen?

Voit varata puhelimitse maksuttoman konsultaatiokäynnin, jossa katsotaan turkin laatua ja sopivaa hoitotapaa.

Miten löydän liikkeen?

Viipurinkatu 18, Alppila, Helsinki. Sisäänkäynti Viipurinkadulta. Tarkemmat ohjeet löydät sijaintisivulta.
