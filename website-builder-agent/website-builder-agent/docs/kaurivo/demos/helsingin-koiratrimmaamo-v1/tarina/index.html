Helsingin Koiratrimmaamon toiminta alkoi vuonna 1975. Sukupolvien koirat ja ihmiset ovat kulkeneet samoista ovista yli viiden vuosikymmenen ajan.

MEIDÄN HISTORIAMME

Pienestä liikkeestä pitkäksi tarinaksi.

Trimmausliike sai alkunsa Tivolitiellä vuonna 1975. Yrityksen oman historiakuvauksen mukaan se on Suomen vanhin edelleen toimiva koirien trimmausliike. Toimintaa on kehitetty vuosikymmenten aikana, mutta koirien yksilöllinen käsittely on pysynyt keskiössä.

VUOSIEN VARRELTA

Toiminta alkaa

Anja Luoso perustaa koirien trimmausliikkeen Tivolitielle Helsingin Alppilaan, lähelle Linnanmäkeä.

1990-luku

Isommat tilat aivan vieressä

Trimmaamo muuttaa aiempien tilojen vieressä sijaitsevaan suurempaan liiketilaan. Yritys tunnetaan pitkään yksinkertaisesti nimellä Koiratrimmaamo.
