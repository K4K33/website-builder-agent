Hinnasto perustuu Helsingin Koiratrimmaamon julkaistuihin hintoihin 1/2026 alkaen. Lopullinen hinta riippuu muun muassa turkin kunnosta, työstä ja koiran käyttäytymisestä.

Hinnaston tiedot · 1/2026 alkaen

Hinnat sisältävät arvonlisäveron 25,5 %. Hinnat ovat suuntaa-antavia ja yritys pidättää oikeuden muutoksiin. Pesu- ja trimmauspalvelut sisältävät kynsienleikkuun; palvelua valitessa huomioi pesupalveluiden 20 kg painoraja.

Peruutusehdot ja maksaminen

Varattu aika perutaan viimeistään 24 tuntia ennen. Myöhään perutuista tai käyttämättä jätetyistä ajoista veloitetaan 50 % palvelun hinnasta. Maksutapoina käteinen sekä yleisimmät pankki- ja luottokortit.
