Etusivu / Osaaminen

Suunnittelu­osaaminen, jota työ tarvitsee.

Suunnittelun painopisteinä ovat koneet ja prosessit. Hankkeen sisältö täsmentyy aina yhteydenoton ja lähtötietojen perusteella.

Painopiste / Koneet

Kone­suunnittelu.

Koneiden ja laitteiden teknisiin kokonaisuuksiin liittyvä suunnittelutarve voi käsittää lähtötietoja, teknisiä rajapintoja ja käytön asettamia vaatimuksia. Tarkka sisältö määritetään aina erikseen.

Kysy suunnittelusta
Suunnittelun kysymyksiä

Mitä kannattaa selvittää?

Hyödyllisiä keskustelun lähtökohtia, ei luettelo vahvistetuista tuotteista.

  • Teknisen tehtävän tavoite ja rajaus
  • Nykyisten järjestelmien reunaehdot
  • Tarvittavien suunnittelutietojen saatavuus
  • Seuraavan vaiheen toteutusedellytykset
Tekninen tarkastelu

Prosessien kokonaisuus

Prosessisuunnittelussa tekninen kokonaisuus muodostuu järjestelmistä, virroista, riippuvuuksista ja toiminnallisista reunaehdoista.

Painopiste / Prosessit

Prosessi­suunnittelu.

Prosessiin liittyvässä toimeksiannossa oleellisia lähtötietoja ovat esimerkiksi järjestelmän tavoite, nykytila ja tekniset rajapinnat. Palvelun soveltuvuus ja laajuus selvitetään yhteydenoton yhteydessä.

Yhteydenotto

Varmista suunnittelutehtävän rajaus.

Kerro nykytilanteesta ja toivotusta lopputuloksesta. Siitä on luonteva aloittaa tekninen keskustelu.
