Etusivu / Hankkeen eteneminen

Kirkkaasta lähtötilanteesta tarkempaan tehtävään.

Teknisen suunnittelun toimeksianto kannattaa aloittaa keskeisten kysymysten selvittämisestä. Alla Kaurivon ehdottama esimerkkimalli.

Esimerkkirakenne · keskustelun tueksi
ENSIN / 01

Tarpeen määrittely

Kerro, millainen laite, järjestelmä tai prosessi on kyseessä. Millainen muutos tai tavoite on ajankohtainen? Hyödyllisiä ovat myös käytössä olevat piirustukset ja tekniset perustiedot.

SEURAAVAKSI / 02

Tekninen rajaus

Varmistetaan, mitkä suunnittelukysymykset kuuluvat toimeksiantoon ja mitä tietoja tarvitaan ennen jatkoa. Soveltuvuus, aikataulu ja mahdolliset rajapinnat arvioidaan tilanteen mukaan.

TARKENNETAAN / 03

Suunnittelun toteutus

Suunnittelutehtävän eteneminen, tuotokset ja yhteistyötapa voidaan sopia, kun lähtötilanne on riittävän selvä. Tämä on sivuston sisältöehdotus, ei väite nykyisistä vakiokäytännöistä.
