Yleisiä kysymyksiä

Kun suunnittelutarve on vielä avoin.

Lyhyet vastaukset teknisen toimeksiannon aloittamiseen.

Miten suunnittelutarpeen voi kuvata?

Kerro mitä pitäisi saada aikaan, mihin järjestelmään tai koneeseen tarve liittyy ja millainen aikataulu on mielessä.

Tarvitaanko valmiit piirustukset?

Aiemmat piirustukset ja tekniset perustiedot helpottavat keskustelua, mutta tarvetta voi kuvata myös ilman niitä.
