Tilaukseen liittyviä kysymyksiä

Minne Castanum toimittaa?

Castanum toimittaa kukkia Helsinkiin, Espooseen ja Vantaalle.

Voinko tilata kukat verkkokaupasta?

Kyllä. Tilauksia voi tehdä eKukka-verkkokauppaan. Katso siellä saatavilla olevat vaihtoehdot ja toimitusehdot.

Kuinka nopeasti tilaus toimitetaan?

Tarkista ajankohtainen toimitusaika verkkokaupasta tai numerosta 041 319 2410.

Voinko kysyä kukkien saatavuudesta ennen tilausta?

Voit soittaa tai kirjoittaa liikkeeseen: kukat@castanum.fi.
