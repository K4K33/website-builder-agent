HYVÄ TIETÄÄ

Tilaukseen liittyviä kysymyksiä

Minne Castanum toimittaa?

Castanumin alkuperäisen sivuston mukaan kukkatoimituksia on Helsinkiin, Espooseen ja Vantaalle.

Voinko tilata kukat verkkokaupasta?

Kyllä. Castanumin alkuperäiseltä sivustolta pääsee erilliseen eKukka-verkkokauppaan. Tarkista sieltä kulloinkin tarjolla olevat vaihtoehdot.

Kuinka nopeasti tilaus toimitetaan?

Toimitusaikaa ei ole vahvistettu alkuperäisellä toimitussivulla. Tarkista ajankohtainen aika verkkokaupasta tai numerosta 041 319 2410.

Voinko kysyä kukkien saatavuudesta ennen tilausta?

Voit soittaa tai kirjoittaa liikkeeseen: kukat@castanum.fi.
