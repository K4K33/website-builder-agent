Laukaassa vuodesta 1999

Yhteistä makumatkaa jo 27 vuotta.

Rosanne aloitti Laukaassa marraskuussa 1999. Ravintolan nimi yhdistää Rosan ja Annen nimet. Täällä ruoka valmistetaan omassa keittiössä, ja pullaa leivotaan joka arkiaamu.

Pullakahvit alkaen 4 €. Mukaan voi tilata myös täytekakkuja, voileipäkakkuja ja muita tarjoiluja. Kesäisin käytössä on terassi.
