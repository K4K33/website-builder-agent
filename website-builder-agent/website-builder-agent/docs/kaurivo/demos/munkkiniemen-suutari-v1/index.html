Samalla paikalla vuodesta 1943

Vanhan ammatin
monta puolta.

Munkkiniemen Suutari on toiminut samalla paikalla vuodesta 1943. Verstaan osaaminen ulottuu perinteisestä suutarintyöstä avaimiin, erikoiskorjauksiin, soitinhihnoihin ja käsintehtyihin tuotteisiin.

Monenlaisia töitä yhdistää halu löytää käytännöllinen ratkaisu. Erikoisemmankin korjaustarpeen kanssa kannattaa tulla näyttämään työtä paikan päälle.
