Polkupyörän huolto, korjaus, varustelu ja käytettyjen pyörien myynti Turun keskustassa.

Huollot ja korjaukset

Visan huoltaa kaikenmerkkisiä polkupyöriä: aikuisten, lasten, tandem-, tavara- sekä sähköavusteisia pyöriä. Tuo pyörä paikan päälle tai soita etukäteen.

Varaosat ja varusteet

Renkaat, rattaat, vaijerit, laukut, tavaratelineet, lukot ja valot. Kysy tarkempaa saatavuutta liikkeestä.

Pyörien kokoaminen

Pyörien varustelu, kasaaminen ja kustomointi kuuluvat liikkeen tarjoamiin töihin.

Uudet ja käytetyt pyörät

Yritys esittelee valikoimaansa myös verkkosivuillaan. Ajankohtaiset pyörät ja hinnat löytyvät alkuperäiseltä myyntisivulta ↗.
