Penny Lane on toiminut Töölössä vuodesta 1993. Alakerrassa odottavat vuosikymmenten vaatteet ja asusteet sekä satavuotias flyygeli ja gramofoni.

Yläkerrasta löytyy juhlapukuja, frakkeja, smokkeja ja muita vaatteita erityisiin hetkiin.
