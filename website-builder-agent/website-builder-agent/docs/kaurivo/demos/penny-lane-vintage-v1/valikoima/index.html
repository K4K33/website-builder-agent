Penny Lanen valikoima vaihtuu, joten tämänhetkiset löydöt ja saatavuus kannattaa tarkistaa suoraan myymälästä.

Valikoima vaihtuu jatkuvasti. Uusimmat liikkeen kuvat ja tiedot löytyvät Penny Lanen Instagramista.

Yksilöllisiä
löytöjä.

Myymälässä on vaatteita ja asusteita eri vuosikymmeniltä: keräilijän helmiä, designvaatteita, kelloja, koruja, kenkiä ja laukkuja.

Juhlapuvut, frakit, smokit ja puvut löytyvät yläkerrasta. Osa vaatteista on saatavilla myös vuokralle.
