Myyntipalvelu

Tuo vaatteesi
myyntiin.

Penny Lane toimii myyntitiliperiaatteella. Voit tuoda hyväkuntoisia käytettyjä tai käyttämättömiä vaatteita, asusteita, kenkiä ja laukkuja myytäväksi.

Näin myynti toimii

Kahden kuukauden myyntijakso.

Kun tuomasi artikkeli myydään, saat itsellesi sovitun osan myyntihinnasta. Tuotteet ovat myynnissä kahden kuukauden ajan.

Myymättömät artikkelit palautetaan sinulle tai toimitetaan halutessasi vaatekeräykseen.

Kysy myyntitilistä
Usein kysyttyä

Mitä tuotteita voi tuoda?

Hyväkuntoisia käytettyjä tai käyttämättömiä vaatteita, asusteita, kenkiä ja laukkuja. Soveltuvuudesta kannattaa kysyä suoraan myymälästä.

Kuinka kauan tuotteet ovat myynnissä?

Penny Lanen ilmoittama myyntiaika on kaksi kuukautta.

Miten myyntiosuus määräytyy?

Myyjä saa sovitun osan myyntihinnasta. Tarkka prosenttiosuus ja muut ehdot sovitaan liikkeen kanssa; niitä ei ole julkaistu alkuperäisellä sivulla.

Entä jos tavaraa ei myydä?

Myymättömät tuotteet palautetaan tai voidaan myyjän toiveesta toimittaa vaatekeräykseen.
