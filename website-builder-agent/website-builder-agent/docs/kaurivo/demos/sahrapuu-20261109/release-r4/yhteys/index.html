Hyvä tietää

Ennen yhteydenottoa.

Sahrapuu valmistaa tilaustöitä yksilöllisiin tarpeisiin. Kysy omasta projektistasi suoraan, niin saat tarkemmat tiedot toteutusmahdollisuuksista.

Voinko kysyä yksittäisestä mittatilauskalusteesta?

Kyllä. Sahrapuun alkuperäisellä sivustolla kannustetaan ottamaan yhteyttä myös silloin, kun sopivaa valmista kalustetta ei löydy.

Entä jos minulla on perintöhuonekalu?

Sahrapuun palvelukuvauksessa mainitaan erikseen mahdollisuus tiedustella perintöhuonekalun kunnostamista.

Onko verkkokauppa jo käytössä?

Alkuperäisen verkkosivun mukaan Sahrapuu kehittää verkkokauppaansa. Verkkotilauksia ei oteta vastaan tämän suunnitteludemon kautta.

Voiko remontista tai asennuksesta tiedustella?

Kyllä. Sahrapuu kertoo tekevänsä pienremontteja, maalauksia, pintaremontteja ja kalusteasennuksia.

Mistä löydän yrityksen tuoreita työnäytteitä?

Sahrapuu kertoo julkaisevansa uutisia ja työnäytteitä Instagramissa ja Facebookissa. Suoria tililinkkejä ei ole vahvistettu tätä demoa varten.

Voinko lähettää tarjouspyynnön tässä demossa?

Tässä suunnitteludemossa ei kerätä eikä lähetetä lomaketietoja. Voit käyttää yrityksen alkuperäisiä sähköposti- ja puhelinyhteystietoja.
