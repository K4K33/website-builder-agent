Yhteydenotto

Kerro ensin tärkeimmät tiedot.

Työn laatu ja koko, kohteen sijainti, mahdolliset nykyiset vauriot sekä toivottu värimaailma auttavat aloittamaan keskustelun. Lopullinen työ ja hinta sovitaan yrityksen kanssa erikseen.

Tämä konseptidemo avaa sähköpostiohjelmasi; se ei käsittele eikä lähetä itsenäisesti tarjouspyyntöä. Varsinaista yhteydenottolomaketta voi käyttää yrityksen alkuperäisellä verkkosivustolla.

Usein kysyttyä

Ennen kuin otat yhteyttä

Teettekö myös koristemaalausta?

Kyllä. Alkuperäisellä sivustolla mainitaan muun muassa ootraus, marmorointi ja muu koristemaalaus.

Voiko tapetointia tehdä myös muualle kuin seinään?

Kyllä. Mainittuja esimerkkikohteita ovat katot, kaapinovet, säilytyslaatikot ja hatturasiat.

Korjaatteko vanhoja ovia tai kalusteita?

Kyllä. Vanhojen ovien, panelointien ja huonekalujen kunnostus kuuluu alkuperäisen sivun palveluihin.

Onko työhuoneessa avoimet käyntiajat?

Aukioloaikoja ei ole vahvistettu tässä demossa. Sovi käynnistä suoraan yrityksen kanssa.
