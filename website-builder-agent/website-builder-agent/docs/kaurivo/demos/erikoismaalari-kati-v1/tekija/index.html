Tekijä & työ

Kati Pakarinen.

Erikoismaalausta, tapetointia sekä huonekalujen ja sisäpintojen kunnostusta yli 20 vuoden kokemuksella.

Katin työhuone sijaitsee Fredrikinkadulla Helsingissä. Työssä yhdistyvät eri materiaalien tuntemus, värien suunnittelu ja huolellisesti toteutetut pintatekniikat.

Ota yhteyttä Katiin

Valokuva: Sofie von Frenckell.

Työn jälki

Huolellista pintatyötä monenlaisiin kohteisiin.

Vanhojen ovien, kalusteiden ja koristepintojen käsittelyssä ratkaisu riippuu kohteen nykyisestä kunnosta, toivotusta lopputuloksesta ja pintamateriaalista.

Kati auttaa myös materiaalien ja värien valinnassa sekä työn suunnittelussa.
