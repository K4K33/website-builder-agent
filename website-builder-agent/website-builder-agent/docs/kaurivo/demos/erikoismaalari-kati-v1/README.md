# Erikoismaalari Kati — Kaurivon itsenäinen ensimmäinen premium-konseptidemo
Tämä on Kaurivon oma, **ei yrityksen virallinen** esikatselutoteutus.

## Virallinen lähde
- https://erikoismaalari.fi/
- https://www.instagram.com/erikoismaalari/ (alkuperäisen sivun Esimerkkejä-linkki)
- Tallennettu ja verrattu aidolla Chromium-selaimella mobiilissa (390) ja tietokoneella (1440).
- Vertailutallenteet ja 20 responsiivisen reitin sekä yhden hiiren liikeinteraktion testin raportti: https://github.com/K4K33/website-builder-agent/actions/runs/42589931237/artifacts/13660558527

## Sivut
- `index.html`: alkuperäinen motiivi ja henkilön/pintojen käsityöosaaminen
- `palvelut/index.html`: maalaus, tapetointi, entisöinti
- `tyot/index.html`: kolmesta autenttisesta lähdekuvasta koostuva galleria ja Instagram-linkki
- `tekija/index.html`: Kati Pakarisen oikea valokuva ja palveluprofiili
- `yhteys/index.html`: alkuperäinen puhelin, email, työhuoneen osoite ja Y-tunnus

## Tämän version rajoitukset
- Kuva- ja logotiedostot haetaan väliaikaisesti alkuperäisen yrityssivuston julkisista osoitteista.
  **Tämä ei ole lupa kopioida tai käyttää kuvia kaupallisesti.** Omistajan lupa ja oma mediahosting vaaditaan ennen toimitusta.
- Sivuston yhteydenotto avaa vain sähköpostiohjelman. Alkuperäinen lomake on linkitetty. Ei teeskenneltyä automaattista lähettämistä.
- Verkkokauppaa ei ole alkuperäisessä lähdeaineistossa havaittu. Ei keksittyä tuotevalikoimaa tai hintatietoa.
- Muokattavaa CMS:ää ja asiakkaan edit/save/publish-testiä ei ole.
- Tekninen QA ei ole riippumaton 9,5/10 visuaalinen arvio. Asiakasvalmius edellyttää erillistä riippumatonta arviointia.
- Ei lähetetty yhteydenottoja eikä muutettu yrityksen omaa verkkosivustoa.
