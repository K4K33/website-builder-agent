## Rakenne
4 sivua (etusivu, palvelut, korjaamo, yhteys), paikallinen CSS ja JS, mobiilivalikko, FAQ, saavutettavuustoiminnot, puhelin, sähköposti, ajo-ohje ja Autofitin ulkoinen ajanvaraus. Ei valekontaktilomaketta. Ei keksittyä logoa, asiakasarvostelua tai hinnoittelua. Kaikki demo-sivut noindex.

## Toimitusehto
Logon ja lopullisten kuvien käyttöoikeudet sekä asiakkaan suostumus, julkisen demojulkaisun selaintarkistus ja muokattava CMS tulee vahvistaa ennen oikeaa asiakastoimitusta. Alkuperäistä sivustoa ei onnistuttu avaamaan ruutupohjaiseen vertailuun tässä ympäristössä; alkuperäisen ulkoasun tarkka säilyttäminen on vielä erikseen todennettava.
