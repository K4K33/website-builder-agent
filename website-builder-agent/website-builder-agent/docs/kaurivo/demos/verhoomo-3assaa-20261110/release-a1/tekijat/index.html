Silvana Hjelt ja Sini Öhman

Ystävyydestä yhteinen verstas.

Verhoomo 3 Ässään tarina alkoi jo verhoiluopintojen aikana. Yhteinen käsityö, luottamus ja halu pidentää kalusteiden elinkaarta näkyvät työn tekemisessä.

Kolmen ässän tarina

Yhteiset opinnot, oma työ.

Silvana ja Sini tutustuivat verhoilualan artesaanin perustutkinnon aikana. Ajatus yhteisestä verhoomosta syntyi jo silloin. Molemmat suorittivat verhoilualan ammattitutkinnon loppuvuodesta 2023.

Aluksi Silvana perusti Verhoomo Rosebudin ja Sini Verhoilupaja Grasslaken. Verhoomo 3 Ässään perustamiseen osallistui myös Suski. Kun Suskin tie vei muualle, yhteistyö jatkui kahden tekijän voimin.

Alkuperäisen sivun päivitetyn tekstin mukaan Silvana työskentelee nykyisin verstaalla, ja Sini toimii taustajoukoissa etenkin isommissa projekteissa. Yhdessä tekeminen ja käsityö kuuluvat yrityksen tarinaan.

Kalusteiden käyttöikä

Verhoilu jatkaa hyvän huonekalun tarinaa.

Kiertotalous on osa verhoomon arkea. Uudelleenverhoilulla huonekalu voi jatkaa käytössä vuosia ja säilyttää oman tarinansa.

Verhoomo palvelee yksityisiä ja yrityksiä Klaukkalasta käsin. Myös kuljetuksista ja kotikäynneistä voi tarvittaessa sopia.
