Hyvä tietää

Tarjouksen saa kuvien perusteella alkuun.

Verhoomolle voi lähettää viestin valokuvineen ja kuvailla, millaista verhoilua tarvitsee. Myös tarvittaessa järjestettävistä kalustekuljetuksista voidaan sopia.

InstagramFacebook Sijainti kartalla
Mitä kuvia tarvitaan tarjouspyyntöön?

Kuvaa koko kaluste ja lisäksi sen kuluneet tai vaurioituneet kohdat. Kerro myös materiaalitoiveistasi.

Voinko sopia kalusteen kuljetuksesta?

Kyllä. Alkuperäisen sivun mukaan verhoomo voi järjestää kalusteiden kuljetuksen ja tehdä sovittaessa kotikäyntejä.

Voiko veneen verhoilusta kysyä?

Kyllä. Yritys verhoilee veneiden istuimia, patjoja, penkkejä ja sisustuspaneeleita.

Saanko kiinteän hinnan heti?

Kohteen kunto, työn laajuus ja materiaali vaikuttavat hintaan. Alustava arvio voidaan tehdä kuvien perusteella; tarkemmat ehdot sovitaan suoraan verhoomon kanssa.

Lähetetäänkö viesti tämän suunnitteludemon lomakkeella?

Ei. Tämä on esikatselu eikä yritykselle hyväksytty viestien keräysjärjestelmä. Käytä alkuperäisiä puhelin-, sähköposti- tai WhatsApp-yhteystietoja.
