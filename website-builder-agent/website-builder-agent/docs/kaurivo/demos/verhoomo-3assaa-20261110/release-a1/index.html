Käsityötä jo vuodesta 2021

Kalusteelle löytyy uusia käyttövuosia.

Verhoomo 3 Ässään perustivat verhoilijakisällit Silvana Hjelt ja Sini Öhman. Kalusteiden uudelleenverhoilu ja kunnostaminen ovat heille käytännön kiertotaloutta.

Klaukkalan verstaalla palvellaan sekä koti- että yritysasiakkaita. Tarvittaessa kalusteen kuljetuksesta ja kotikäynneistä voidaan sopia.
