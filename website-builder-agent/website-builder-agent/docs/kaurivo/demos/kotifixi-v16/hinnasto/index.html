KOTITALOUSVÄHENNYS

Voiko työstä saada vähennyksen?

Osasta kodin ja pihan töistä voi saada kotitalousvähennyksen. Vuosina 2026–2027 vähennys on 40 % hyväksyttävän työn osuudesta, enintään 2 100 € henkilöltä vuodessa. Omavastuu on 150 €. Kaikki työt eivät kuulu vähennyksen piiriin. Varmista myös palveluntarjoajan ennakkoperintärekisterimerkintä ennen tilausta. Tämä ei ole lupaus Kotifixin yksittäisen palvelun vähennyskelpoisuudesta.
