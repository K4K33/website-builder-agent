KORJAAMOPALVELUT

Huollot, korjaukset ja katsastus

01

Määräaikaishuolto

Valmistajan huolto-ohjelman mukaiset huollot sekä öljy- ja suodatinvaihdot.

02

Korjaamopalvelut

Vikadiagnostiikka, korjaukset, jarrut, kytkin- ja jakopäätyöt.

03

Katsastus ja ilmastointi

Katsastustarkastukset, katsastuksessa käyttö ja ilmastointihuollot.

04

Pikahuolto

Äkillisten vikojen kartoitus ja pienet huoltotyöt saatavuuden mukaan.

05

Sijaisauto

Mahdollisuus sijaisautoon huollon ajaksi. Tiedustele varaamisen yhteydessä.

06

Renkaat ja maksutavat

Rengastyöt, kausisäilytys sekä Fixus-laskun maksuvaihtoehdot.
