Tietoa Etikistä

Neljä tekijää, monta osaamisaluetta.

Etikki on Pohjois-Helsingissä toimiva perheyritys, joka on tehnyt verhoilua 1990-luvulta lähtien. Puuverstas perustettiin 2000-luvun alussa.

Verstas Helsingissä

Kalusteita koteihin ja julkisiin tiloihin.

Etikki tarjoaa huonekalujen kunnostusta, verhoilua ja puusepäntöitä. Yritys suunnittelee ja toteuttaa myös ravintolakalusteita, baaritiskejä, pöytiä, looseja sekä ulkotilojen terasseja ja piharakenteita.

Vanhan kunnostamisen osaaminen ja uusien mittatilauskalusteiden valmistus kuuluvat samaan verstaaseen.
