Voit vastata lyhyesti tai yksityiskohtaisesti. Toiveesi auttavat lopullisen ehdotuksen suunnittelussa. Sovimme työn sisällöstä yhdessä ennen aloitusta.

Esimerkiksi

Palvelut, omat valokuvat, ajanvaraus, nykyinen logo ja värit, eri kielet, yhteydenottolomake tai itse päivitettävä sisältö.

Voit myös vastata suoraan sähköpostiin, jossa lähetimme demon. Lomaketta ei ole pakko käyttää.

Mitä haluaisit lopullisille verkkosivuille?

Vain välttämättömät toiveet ovat pakollisia. Et tarvitse tunnusta etkä maksa mitään.

Nämä ovat suunnittelutoiveita eivätkä kuvien käyttö- tai vaihtolupia. Varmistamme oikeudet ja sovimme muutoksista erikseen.

Lomake käyttää FormSubmit-palvelua. Vastaanottajan sähköpostiosoite täytyy vahvistaa, ennen kuin toimitus toimii. Voit myös vastata suoraan demon sisältäneeseen sähköpostiin. Toiveista sovitaan vielä erikseen ennen toteutusta.
