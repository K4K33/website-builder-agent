# Kaurivo: original-site experience parity — 2026-11-03

**Permanent, cross-industry standard.** A redesign must preserve the original business's meaningful visual richness. Tidy cards and modern typography do not make up for removing original work video, galleries, photo storytelling, tactile backgrounds, or brand recognition.

## Mandatory original-site audit
1. Inspect all important original routes at 320, 390, 768, 1440 pixels and capture first-fold + long-page screenshots and interaction recordings. Inspect actual CSS/JS at runtime; source HTML alone cannot establish the presence or absence of effects.
2. Inventory original logo/wordmark, genuine company photos, work video, products, photo galleries, texture/background assets, visual layers, transitions, hover/focus states, and any genuinely active 3D. Record URL, provenance, uncertainty and reuse permission per asset.
3. Classify the observed motion baseline as restrained, moderate or rich. If the original is rich, preserve comparable business-relevant richness; if the original is restrained, do not automatically add decorative 3D/animation.
4. Keep purposeful motion: studio/workshop video and authentic craft photos normally communicate trust better than a generic SVG shoe, decorative numbers, repeated arrows or blank cards.
5. If source media is protected and permission unavailable, DO NOT silently replace it with invented client assets or certify the demo as premium. Request properly licensed media, obtain owner permission or leave it unapproved. A screenshot of the public site is evidence for planning, not permission to republish.
6. Side-by-side browser QA checks photographic prominence, genuine logo treatment, gallery behavior, depth/textures, actual copy and routes, native scrolling, keyboard, reduced motion, and real mobile speed.
7. All demos, including directly authored GitHub Pages HTML, must pass objective universal quality checks. Automatic tests cannot certify independent 9.5/10 art direction.

## Programmatic changes
- The free original-source experience inventory collects observable video, galleries, source images, textured inline backgrounds, 3D and motion indications plus external CSS/JS inspection requirements.
- The per-company brand blueprint inherits an effect budget. Builder instructions prioritize meaningful original richness and prohibit unapproved synthetic identity.
- Universal quality auditing blocks visibly lost source video and photo-heavy originals stripped of all media, while flagging gallery/texture/runtime gaps for real browser review.
- The new changed-demo CI checks any edited static site folder even when manually published and the Builder preflight was bypassed.
- No paid API credit is consumed by this offline inspection. Client rights clearance and independent perceptual QA are still required.

## Rejected example and root cause
The 2026-11-03 Munkkiniemen Suutari / ROOTS LTD concept, despite its technically completed six pages and earlier green tests, is not quality-approved. The original displays its actual logo, real workshop/product photographs, galleries, video, and rich material backgrounds. The concept uses an unapproved M monogram, a decorative SVG shoe, 43 numerals, repeated arrows and flat panels. These are documented regressions, not evidence of a 9.5/10 rebuild.

**Release states must stay separate:** built → objective checks → real original-to-new media/browser parity → independently reviewed visual quality → owner rights and content approval → client release.
